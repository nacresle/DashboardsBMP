# Dashboards del Bosque Modelo Palencia (BMP)
El Bosque Modelo Palencia es una iniciativa territorial orientada a promover la gestión sostenible de los recursos naturales y el desarrollo social y económico del territorio mediante la colaboración entre administraciones, entidades, propietarios, investigadores y otros actores locales. El territorio se extiende por el norte de la provincia de Palencia y comprende alrededor de 4.067 km² y más de 90 municipios, integrando una gran diversidad de paisajes y recursos forestales.

Para más información sobre el Bosque Modelo Palencia:
[🌐 Bosque Modelo Palencia](https://palenciabosquemodelo.es/)

Este repositorio contiene los dashboards (en png) desarrollados para la visualización, exploración e interpretación de información forestal del Bosque Modelo Palencia a escala de parcela del Inventario Forestal Nacional (IFN) y municipio para las masas dominadas por pinares y robledales. Los dashboards integran información procedente de diferentes fuentes de datos forestales (IFNs, MFEs, Límites administrativos, datos climáticos...) y permiten consultar indicadores relacionados con el estado, estructura, composición, existencias, crecimiento, daños y otros aspectos de los ecosistemas forestales.
